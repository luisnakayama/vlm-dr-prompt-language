# Prompt language and diabetic retinopathy grading by open medical vision-language models

Code and prompts for the study **"Prompt Language Shifts Diabetic Retinopathy Grades of Open Medical Vision-Language Models:
English Versus Portuguese Instructions in Brazilian Fundus Photographs"** (manuscript under review).

The study compares English and Portuguese prompts for zero-shot International Clinical Diabetic Retinopathy
(ICDR) grading by MedGemma 4B and MedGemma 27B on two Brazilian datasets: BRSET (tabletop cameras) and mBRSET
(handheld camera). A 2 × 2 factorial experiment separates the language of the instructions from the language of
the answer format.

## Data

BRSET and mBRSET are available on PhysioNet under credentialed access:

- BRSET v1.0.1: https://doi.org/10.13026/1pht-2b69
- mBRSET v1.0: https://doi.org/10.13026/qxpd-1y65

**No images, labels or image-level predictions are included in this repository**, in accordance with the
PhysioNet data use agreement. Only code, prompts and aggregated result tables are shared.

## Prompts

All prompts are in [`settings/prompts.yaml`](settings/prompts.yaml):

| Key | Instructions | Answer format |
|---|---|---|
| `main_en` | English | English |
| `main_pt` | Portuguese | Portuguese |
| `pt_instr_en_fmt` | Portuguese | English |
| `en_instr_pt_fmt` | English | Portuguese |

`nodef_en` (English prompt without grade definitions) was used only in a robustness analysis and is not part of
this study. In every prompt the answer is prefilled with `ICDR: `, so that the first generated token is the grade.

## Models

Model identifiers and fixed Hugging Face revisions are in [`settings/models.yaml`](settings/models.yaml):

| Model | Hugging Face identifier | Revision |
|---|---|---|
| MedGemma 4B | `google/medgemma-4b-it` | `290cda5eeccbee130f987c4ad74a59ae6f196408` |
| MedGemma 27B | `google/medgemma-27b-it` | `2d3e00ea38b50018bf5dd3aa1009457cd2d5a48f` |

Inference: no system message, greedy decoding (at most 16 new tokens), images at 896 × 896 pixels, bfloat16.
MedGemma 4B was run on an Apple M5 Max laptop (MPS) and MedGemma 27B on a single NVIDIA A100 80 GB GPU.

## Repository structure

```
config.py               paths (set by environment variables) and fixed parameters (seed, bootstrap)
settings/prompts.yaml   prompts
settings/models.yaml    models and revisions
vlmdr/cohort.py         cohort definition (BRSET: patients with diabetes; mBRSET: macula-centered images)
vlmdr/infer.py          local inference with Hugging Face transformers; grade and edema probabilities
vlmdr/prompts.py        answer parsing
vlmdr/metrics.py        kappa, cluster bootstrap, clustered McNemar and DeLong tests
vlmdr/errors.py         error types, language comparison and factorial analysis
vlmdr/runner.py         runs the inference steps with resume
notebooks/              analysis notebooks (generated by build_notebooks.py; outputs removed)
results/tables/         aggregated results of the language analyses
tests/smoke_test.py     test with synthetic data (no real data or models needed)
```

Notebooks relevant to this study:

| Notebook | Content |
|---|---|
| `00_coorte.ipynb` | cohort and exclusion flow |
| `03_inferencia_gpu.ipynb`, `03b_inferencia_local.ipynb` | English prompt (main run) |
| `05_extra_gpu.ipynb`, `05b_extra_local.ipynb` | Portuguese prompt and factorial experiment |
| `06_erros_vieses.ipynb` | language comparison, error types and factorial effects |

The remaining notebooks belong to the companion study on grading accuracy. Code comments and notebook text are in
Portuguese.

## Reproducing the analysis

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt            # requirements-gpu.txt for the CUDA machine
huggingface-cli login                      # accept the MedGemma (HAI-DEF) license first
python tests/smoke_test.py                 # synthetic data only
```

Set the paths to the PhysioNet files with environment variables (see `config.py`): `BRSET_LABELS`,
`MBRSET_LABELS`, `BRSET_IMAGES`, `MBRSET_IMAGES`. Then run the notebooks in the order above.
`rodar_nuvem.sh`, `preparar_nuvem.py`, `vigiar_nuvem.sh` and `gpubrasil.py` are helper scripts used to run
MedGemma 27B on a rented GPU; API keys and tokens are read from environment variables and are not included.
